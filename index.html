FeverGuard AI — Smart Healthcare Monitoring

An intelligent IoT-based healthcare system that continuously monitors body temperature via ESP32-C6 & DS18B20, generates automated digital fever charts, and uses a custom-trained ML model to analyze fever patterns for clinical decision support — recommending probable conditions, investigations, and medical specialties. AI Music Analyzer & Guitar Assistant

A full-stack platform that uses audio signal processing and Music Information Retrieval to analyze uploaded songs — detecting BPM, key signature, time signature, mood, and chord progressions. Features interactive guitar chord diagrams, piano note visualization, auto-generated chord sheets with PDF export, real-time transpose, and a guitar-part composer with playback.

AI Traffic Violation Detection System

A real-time computer vision system that detects motorcycle helmet violations using YOLOv8 and automatically extracts vehicle number plates via EasyOCR. Combines object detection, rule-based logic, and OCR with a Flask dashboard for live monitoring, violation search by plate number, evidence viewing, and CSV/PDF report export.
