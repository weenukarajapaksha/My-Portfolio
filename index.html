SoundScout AI — AI-Powered AV Equipment Rental Marketplace

A full-stack, two-sided marketplace connecting event organizers with AV equipment vendors across Sri Lanka. A LangGraph-orchestrated pipeline of specialist AI agents (Audio, Visual/Lighting, Logistics) powered by Gemini generates tailored equipment plans, cross-checked against a scikit-learn Random Forest model for realistic pricing — automatically re-scoping if a plan exceeds budget. Vocal Enhancer — Real-Time Voice Processing App

A lightweight, open-source desktop alternative to Auto-Tune/Voicemod. Streams mic input through a low-latency PortAudio duplex engine into a configurable DSP chain — noise gate, YIN-based pitch correction with key/scale snapping, dual-voice harmony, compressor, 3-band parametric EQ, robot voice, delay, and Freeverb-style reverb — all tunable live from a PySide6 dark-themed GUI with saved presets and level meters. Also loads WAV/FLAC/OGG/AIFF files to run the same effect chain offline.
